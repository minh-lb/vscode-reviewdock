# ReviewDock

Review GitHub Pull Requests and GitLab Merge Requests directly in VS Code.

## Features

- Multiple GitHub and GitLab accounts.
- File tree, Unified/Split diffs, and Markdown Source/Rich views.
- Inline comments, replies, and supported thread actions.
- Edit request titles, descriptions, assignees, reviewers, and labels.
- View commits, checks, pipelines, and approvals; merge supported requests.

## Get started

Requires VS Code desktop **1.140.0+**.

1. Install **ReviewDock** (`minhluu.reviewdock`) from Marketplace.
2. Open ReviewDock → **Add Connection** and enter your provider URL and personal access token.
3. Select a repository and open a pull or merge request.

Tokens are stored in VS Code SecretStorage. Requests go directly to your provider. No telemetry is collected.

**Preview:** live write workflows and Enterprise compatibility are not fully verified. Markdown rendering supports a limited subset.
